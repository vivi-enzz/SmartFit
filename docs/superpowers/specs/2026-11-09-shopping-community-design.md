# SmartFit 2.2 试衣与购物社区设计

用户授权沿推荐方向直接实施，参考四张图：暖色空间/玻璃控制、深色服装材质工具、日常穿搭内容流、模特图商品推荐。沿用Vue/Express/SQLite/Three，保持繁體/English、账户及订单。

采用现有3D引擎增加试穿/服装独立模式、全身/上身/织物镜头、暖色空间和深色编辑台；服装参数之外的视图选择不写入订单。添加连帽卫衣类型（基础698HKD），有兜帽、抽绳、袋口、罗纹袖口及衣摆；固定短衣长、长袖、圆领、经典剪裁，可外搭，后端校验并报价。既有连衣裙/上装价格不变。

工作室悬浮工具栏支持最多40步撤销/重做，涵盖配置与风格切换；新路由重置历史，异步初始化完成才启用记录。原有身体数据仍需明确同意后保存，不把标准码当合体预测。

首页增加本地模特摄影的订制风格商品卡，显示基于真实参数的起始价、配色、收藏/进入工作室。摄影为编辑参考，非精确商品图；无需伪造商品库存/销量。

社区主信息流先呈现日常图文、内容类型入口和关联可订制方案；实际用户发布、点赞、评论、收藏继续使用持久化数据。编辑内容清楚署名与来源，不伪造用户或互动数字。详情增加图上关联造型标签，能查看关联设计，不声称照片衣物为在售精确同款。新增本地有授权摄影、来源及授权页。

不接入真实支付、真实明星账户或第三方社交发帖；不提供人体照片换装/物理布料仿真。保留同源/本地HTTP安全修正。工具可用时做浏览器检查，否则明确SSR/几何/HTTP验证限制。
