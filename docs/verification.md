# 实际验证记录

验证环境：Node.js 24.22.1，npm 11.9.0，Linux。日期：2026-11-07。

## 已执行

- `npm test`：29 项通过，0 失败。
  - 14 项 SQLite/API 集成测试：匿名拒绝、演示会话隔离、注册/登录/退出、目录及天气降级、设计兼容性和服务端价格、尺寸同意/范围/加密、订单快照与幂等创建、支付失败重试与事件去重、履约状态、社区互动、图片大小/内容/归属、定位范围、导出与来源校验、重启后持久数据及尺寸解密。
  - 3 项前端共享模型测试：比例变化、数字与范围校验、状态和报价。
  - 9 项 Vue 页面编译/SSR 渲染检查：主页面模板编译及初始内容，不涉及浏览器交互。
  - 3 项路由资源回归测试：切换资源、旧响应晚到、失败时清理旧内容。
- `npm run build`：Vite 生产构建通过。Three.js 延迟加载分包约 705 KB（gzip 181 KB），触发默认体积提示；不会阻止构建，后续可继续精简 Three.js 引用。
- `npm run test:production`：1 项通过。通过 Express 的 HTTP 测试接口验证构建首页、嵌套路由、JavaScript 静态资源、健康接口及 API 404。此检查不启动浏览器或对外预览服务器。
- 独立代码审阅完成；帖子/结算页面复用旧数据的问题已通过共享路由加载逻辑修复并增加失败到通过的回归测试。

## 未验证与限制

当前 managed cloud 环境未提供 `cua_repl.js` 浏览器控制工具；按 Sites managed preview 规则未安装替代浏览器或启动另一条预览通道。未完成真实浏览器点击、手机截图、WebGL 渲染或视觉对比检查。响应式 CSS 与 WebGL 降级代码已实现，但不把源码检查等同于浏览器验证。

未接入九家外部供应商，因而没有真实支付、签名 webhook、短信、OAuth 或物流集成验证。未运行 MySQL schema，未验证真实制造端或生产环境部署。没有测量报告要求的 p95、预览延迟、服务可用性或 WCAG 合规。数据库读写采用单进程 SQLite，缓存与限流也为单进程，不宣称横向扩展。
