# SmartFit 2.0 演示补充

默认入口为同源的 `npm run dev`，终端显示 SmartFit 2.0 和 http://localhost:5173。请先停止旧服务再更新完整源码。页首可切换繁體/EN；首页与社群使用真实摄影的编辑精选，个人发布与点赞仍正常工作。工作室提供更详细的数字人体，正面/侧面/背面切换，旋转、参数和领口更新；模型未进行真实合体预测。

下列原有业务演示流程仍适用，按钮默认以繁體显示。

# 课程演示操作说明

## 建议演示顺序（约 5–8 分钟）

1. **首页**：展示品牌、城市切换和三种天气相关面料。所有天气标注为演示；可在接口查询参数中加入 `simulateFailure=1` 检查降级，不宣称实时数据。
2. **账户**：使用一键演示，展示独立账户；不要退出后期望再次找回。需要复用时注册虚构邮箱账户。
3. **工作室**：改变颜色与 A 字/修身廓形；切换丝绸/亚麻；展示 V 领、袖长、裙长、刺绣。上装仅允许短款；羊毛不允许无袖。
4. **身形**：调节身高与围度，旋转模型。尺寸范围为身高 140–200、胸围 65–140、腰围 50–130、臀围 70–150 cm。只有勾选同意并保存才传输尺寸。
5. **设计**：保存，跳转“我的设计”，再次打开检查配置仍在。下单后改变设计，也不会影响既有订单。
6. **社区**：从设计点击分享，选择设计、生成本地模板文案并编辑，上传 JPG/PNG/WebP（5 MB 内）。发布后点赞、评论，点击“定制这一套”。
7. **结算**：填写虚构姓名、电话与地址，勾选演示声明。创建订单后进入明确标注的模拟支付窗口。
8. **付款与履约**：先点“测试支付失败情形”，再点“模拟支付成功”。依次推进制作、发货、签收。状态由服务端验证并持久化；不是前端随意修改。
9. **服务与隐私**：查看示例合作商/普通店铺区分、城市选择、定位权限拒绝后的手动模式；账户页导出个人数据、删除身体尺寸。

## 状态说明

`pending_payment → paid → in_production → shipped → delivered`。

付款失败仍为 `pending_payment`，记录失败事件并允许重试。仅 `pending_payment` 可以取消为 `cancelled`。不提供已经制作后的退款操作；真实争议、退款和制造异常恢复流程留作生产扩展。

## 本地数据

重启服务后注册账户、设计、帖子、订单和密钥均保留。清空数据请停止服务并先备份完整 `backend/data/`，再自行删除该目录。重新启动会生成新的数据库、密钥和编辑部种子帖子。不要在需要保留数据时操作重置。

## 2.1 新体验检查

在穿搭灵感查看四列网格、活动日期、话题与收藏；收藏保存在当前浏览器并按账户隔离。点击 Instagram 原帖按钮后才连接平台，受平台限制时打开原帖链接。授权页可查 CC 图片与来源。

在工作室切换四套风格，比较经典、细褶、裹身及分层裙摆，再添加短外套或长背心并选配色。使用织物近景、前侧背角度检查材质；二维订单预览也保留剪裁和层次。此为视觉设计演示，不预测真实合体。

在城市服务拖动地图、使用加减缩放、点列表和标记查看联动；定位同意后显示位置及5公里圈。店铺是示例，底图真实；断网时仍可看列表。

## 2.2 空间试衣与购物社区

从首页风格推荐选配色，点击“试穿与设计”进入对应方案。摄影为穿搭灵感，实际预览与报价对应可编辑配置。工作室在暖色空间试衣间与深色服装设计台间切换；试全身、上身、织物镜头，选择连帽卫衣观察兜帽/抽绳/袋口，切换面料与色盘。撤销/重做保留最多40步配置修改。未登录保存会暂存到当前浏览器会话，登录后恢复。

社区优先展示日常摄影选集，使用推荐/日常/IDOL/用户分享筛选；编辑图与真实用户投稿分开标注。点击帖子图片标签或下方风格提案进入工作室，收藏、点赞、评论均由使用者实际操作。手机端快捷底部导航进入探索/社区/工作室/收藏/账户。页面底部及终端均显示2.2.0。
